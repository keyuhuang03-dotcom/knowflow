# 网站功能说明

更新：2026-11-13。按当前网站实现组织，不按分支组织。已实现不等于本次重新验收或已部署至正式站；运行条件见 [开发说明](development.md)，产品规则见 [PRD](prd/PRD.md)。

## 从哪里开始

手机底部入口为首页／知识库／练习／笔记。首页拍错题；知识库查看知识和关联材料；练习把资料变成可作答题集；笔记记录课堂内容。桌面还保留我的错题、学习记录和设置。

## 知识库与图谱

数学 → 高等数学默认显示极限网状图谱，数学一局部参考包含 7 个节点、14 条关系。支持关系筛选、点选相邻高亮、知识详情、关联材料、缩放拖动复位和帮助。默认全部真实关系，点选不重排。图谱进度只有未学、学习中、已学，不代表掌握率。

可以手工创建独立 MD 笔记，引用多个知识点；从知识详情及反向链接找回内容。内置结构只读；数学其他部分和 408 分区保持隔离。教材目录上传不是使用极限图谱的前提，历史教材入口仍保留。

## 错题

首页拍照或错题列表添加 → 多页照片裁剪/旋转/排序 → 保存照片、记录及任务 → 后台识别题干和生成解答 → 用户填写卡点、核对错因和知识关联 → 回看或记录复习。

支持 JPG/PNG/WebP，多页默认最多 6 页；HEIC 需转换。任务失败保留照片，支持重试恢复。用户个人卡点/错因不应被后台覆盖。旧 Skill 诊断和导出保留兼容，不是保存必经流程。

## 课堂笔记

`/notes` 上传图片/PDF → 后台转录与知识点推荐 → 校对标题、正文及多个关联 → 确认独立 MD → 从笔记或图谱打开。历史笔记从专用入口访问。

数据库中的识别草稿不是确认后正文的另一编辑来源。资料校对输入不会被轮询替换，但尚未持久自动保存，刷新可能丢失未确认修改；知识页的 MD 编辑草稿机制与之不同。

## 资料练习

`/practice` 上传图片或最多 12 页 PDF → AI 提取原题/原答案/页码 → 校对并确认 → 作答 → 判题或自评 → 可收入错题。不会自动创作新题或补猜资料缺失的答案。

有源答案的单选题自动判定，其他情况自评。题集和作答存 SQLite；目前没有完整历史/续做界面、确认后题集编辑或可移植题集导出。详见 [资料说明](materials.md)。

## 已有兼容功能

教材目录支持多页识别、预览确认及追加/替换，旧目录和关联保留。学习记录保存科目与时长；今日任务、每日复盘、数据分析与设置页面继续存在。旧笔记和错题未批量迁移。

注意：首页仍显示旧“已掌握”统计；旧分析把较少学习时长称为“薄弱科目”、把记录较集中的时段称为“最高效率时段”。这些标签不是能力证据，也不是规划中的全局薄弱点分析；需要后续统一口径，本轮只记录问题。

## 数据与恢复

新增知识点/笔记/错题正文保存在 MD，附件独立；学习状态、任务、候选、练习集与作答在 SQLite。内容索引可以重建，个人状态不能当索引删除。

- MD＋附件：恢复正文及文件中的关联，不含全部个人/运行状态。
- 学习状态快照：额外覆盖知识进度和复习事件，不含练习作答。
- 完整备份：包含对应数据库、vault、附件、任务与候选；程序、配置另保留。

设置页旧 JSON 导出不等于新增内容的完整备份。准确操作见 [内容与恢复说明](pilot-md-limit.md)。

## 可用条件和验证限制

新图谱、MD 及资料服务依赖现有隔离启动配置，资料 API 会检查数据目录；普通启动不能自动获得全部新功能。PDF 依赖 Poppler，后台 AI 依赖模型配置和运行中的 Worker。

前轮有隔离浏览器、恢复与简单真实 AI 样本记录，本轮仅代码/文档核查。复杂中文手写、密集图谱、Safari 真机、整体内容校对仍需验证。App、多端同步、全局薄弱点分析尚未实现。
