# 当前功能说明

现状和验证日期见 [项目现状](current-status.md)。本页只描述当前流程，不把历史计划当已完成。

## 错题录入与整理

1. 进入“拍下错题”或“添加错题”；支持相册多选和连续拍照，默认每批最多 6 页。
2. 图片可逐页旋转、排序、移除；裁剪直接拖动照片四边/四角，点应用确认，或重置未应用范围。
3. 客户端压缩最长边到 2400px，保留本地草稿。JPG/PNG/WebP 可用；HEIC 需转换或使用兼容相机格式。
4. 上传成功后照片、错题和后台任务已经保存，可以退出；浏览器只查询状态，不承担后台执行。
5. Worker 识别题干并独立生成标准解答/答案/方法/中性错因选项。失败保留照片，支持有限重试与恢复；已完成识别可以复用检查点。
6. AI 推荐已有知识点，用户核对；不编造知识点，不把模型建议当成用户已确认的错误原因。

题干不清、符号不确定或整页多题需要核对，不能仅凭流畅的解答文字当作识别正确。真实模型准确率仍需样本评测。

## 复习卡片与个人复盘

- 标准解答分步显示，答案和提醒分层；标题、选项、摘要和正文都复用公式渲染。
- 卡点由用户填写；错因可以多选、自填或留空。AI 不必先看懂学生手写步骤，不自动诊断用户实际错因。
- “保存卡点与错因”“保存补充”“完成本次复习”都会保存当前卡点、错因与补充；后台完成、重试和人工校对不能覆盖 selfReport。
- 原有 Skill 诊断档案、修订和 Word 下载保留为历史兼容能力，不是新错题必经步骤。

## 教材、目录和知识库

- 数学分为高数、线代、概率统计；408 分为数据结构、组成原理、操作系统、网络。
- 教材目录支持多页上传、后台逐页识别、进度和恢复；标题、页码和树形归属均需核对。
- 总览展示章，展开看节和小标题；页码显示“第 N 页”，不重新加“首项”。
- 识别完成进入预览（ready），不等于已保存；用户确认后才导入并显示已归档（saved）。
- 支持替换或追加。旧目录归档，错题、笔记和关联保留；未确认旧节点不冒充当前教材目录。
- 知识节点可关联学习内容；已有图谱、笔记、任务、学习记录、分析与每日复盘保留。新版图谱及 Obsidian 双向同步不在已交付范围。

## 手机与桌面

≤768px：手机首页突出拍错题、录目录，展示最近错题/目录任务及真实状态；知识库使用紧凑学科卡片，无教材不显示空进度；底部首页/知识库/拍照/记录样式一致，只高亮当前项。原菜单仍可进入其他功能。

桌面保持管理、图谱、分析与复盘布局。错题筛选框等宽、题数居中；手机搜索独占一行避免筛选项拆行。保留奶白、青柠绿、Liquid Glass 和柔和手绘风格。

## 限制

当前为单人持久磁盘部署。未完成公开多租户、生产灾备全流程演练、Safari 真机完整验收及系统性模型准确率评测。GitHub 推送、本地构建、线上上线和模型质量验收是不同状态。
