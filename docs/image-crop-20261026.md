# 图片直接裁剪

共享多页图片入口移除四个百分比滑条，改用照片上的四边与四角拖动框。支持鼠标、触控、方向键微调、重置和应用；未应用时阻止上传或切换页面，收起裁剪时取消未应用范围。边框触控区域为 44px，拖动使用指针捕获，不拦截图片之外的页面滚动。

保留最长边 2400px、格式/像素/上传大小校验和本地草稿。裁剪允许定位角落小题，横纵各至少保留 5%，服务端原有上传流程不变。题目与目录共用此入口。

验证：图片几何单元测试、类型检查、生产构建通过；lint 无错误（3 个既有警告）。隔离数据库浏览器测试覆盖 390px/1440px 四边鼠标拖动、真实 Chromium touch 事件拖角、超过 40% 的裁剪、400×400 实际输出、多页保留、旋转、无横向溢出及运行时错误。

未验证：iPhone Safari 真机和系统相机权限。
