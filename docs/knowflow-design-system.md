# KnowFlow 全站视觉统一

以已验收的紧凑版「我的知识库」为唯一基准，采用方案 B：透明渐变、边缘高光、柔和阴影和 12px 背景模糊。

## 组件与文件

- `app/src/app/knowflow.css`：颜色、玻璃、圆角、阴影 tokens，以及业务页面的 scoped 样式。奶白 `#FAFAF7`、品牌青柠 `#C5E86C`、卡片圆角 22px、输入框圆角 12px。不支持模糊或要求更高对比度时使用实色降级。
- `KnowFlowShell`、`KnowFlowTopbar`：统一内容边距、顶部搜索和账户入口。普通页面搜索现有功能入口；知识库保留原有知识点搜索。
- `KnowledgeSidebar`：复用原有吉祥物和导航，按路由显示当前项，移动端抽屉导航。
- `KnowledgeHome`：只提取顶部组件，保留既有视觉；`GlassCard` 与 `/design-lab` 保持既有实现。
- 首页：现有知识点、错题和学习时长的只读概览、最近活动、快捷入口。
- `MistakeList`：本地关键词、科目和复习状态筛选，展示已有知识关联。
- 学习记录：保留记录功能，历史记录采用轻量时间线；设置保留保存、导入和导出，统一表单分组。
- 笔记、任务、分析、复盘、科目目录、节点详情、错题录入和详情、知识图谱：通过共享 shell 和已有 card/wb 组件统一外观，保留各自布局。
- `Charts`：统一柔和辅助色。没有新建每日复盘或分析功能。

## 验证

- lint：无错误，3 个已有警告（笔记图片 2 个、GraphView effect 1 个）。
- typecheck、webpack 生产构建：通过。
- 原有测试：14/14 通过。
- 独立 Chrome：15 个路由在 1366px、390px 下 HTTP 200、无横向溢出、无页面脚本异常；临时数据库中验证错题筛选、清除筛选、学习记录保存、姓名保存。
- Safari 实机和 iPhone Safari 尚未验证。已保留前缀模糊、实色降级和移动表单 16px 字号；不能将 Chrome 模拟宽度视为 Safari 实机结果。

可选只读回归：配置 `KNOWFLOW_PLAYWRIGHT`（已安装 Playwright 路径）、`KNOWFLOW_CHROME`（浏览器可执行文件）、`KNOWFLOW_TEST_URL` 后运行 `node app/tests/site-ui.browser.mjs`。使用包含 math 科目的测试数据；详情页面及写入交互在隔离数据库中单独验收。

## 本地验收

1. `npm --prefix app run dev`，打开 http://127.0.0.1:3000/。
2. 在首页、知识库、错题、学习记录、设置之间切换，检查导航高亮、顶部搜索、卡片与按钮的一致性。
3. 检查错题筛选与详情、学习记录弹窗和设置保存；修改真实数据前自行决定是否保存。
4. 缩窄浏览器或使用手机，检查导航抽屉、表单、长文字和弹窗；在 Safari 重点检查玻璃边缘与文字清晰度。

该视觉系统已用于现有站点。≤768px 的手机录入优先布局与桌面差异化；导航只高亮当前项。运行版本和验证范围以 current-status.md 为准，发布按 aliyun-deployment.md 执行。
