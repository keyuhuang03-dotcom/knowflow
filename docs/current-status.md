# 网站实现现状与已知缺口

核对：2026-11-13。本文以功能为主，不以分支划分产品；依据为当前代码、配置脚本和已有验证记录。本轮未重新执行浏览器/模型测试，也未核验正式服务器版本。

## 实现范围

| 模块 | 当前实现 | 主要边界 |
| --- | --- | --- |
| 知识库 | 学科入口、数学一极限 Reagraph 图谱、详情与相邻导航、材料关联 | 7 节点/14 关系的局部参考包，不是完整高数 |
| 内容 | 独立 MD、稳定编号、链接/反向链接、编辑冲突保护和索引恢复 | 不支持任意外部移动/删除或实时同步 |
| 错题 | 多页照片先存、后台整理、用户卡点/错因与关联、复习记录 | AI 不是用户实际错因的事实来源 |
| 笔记 | 手工创建、照片/PDF 转录、校对关联后写 MD | 上传资料校对草稿刷新保护未完整 |
| 练习 | 提取原题、校对、判题/自评、收入错题、保存作答 | 缺历史/续做界面、确认后编辑和独立迁移格式 |
| 原有功能 | 教材目录、旧笔记/错题、时长、任务、每日复盘、设置 | 未批量迁移；旧统计不能等同新图谱状态 |
| 数据保护 | 持久队列、版本检查、MD 写入恢复、完整备份与隔离恢复工具 | 设置旧 JSON 与新完整备份不是同一覆盖范围 |

流程与规则见 [PRD](prd/PRD.md)，面向使用者的简要说明见 [功能说明](features.md)。

## 当前需要纠正的产品口径

1. 首页从旧 KnowledgeNode 统计“已掌握”，没有统一读取新 LearningProgress；不能宣传全站统一掌握评价。
2. 数据分析按学习时长推导“薄弱科目”和记录高峰时段，不能据此评估能力或效率。未来全局薄弱点分析尚未实现。
3. 笔记/练习资料编辑器不会被轮询覆盖，但未确认修改尚不能可靠跨刷新恢复；MD 编辑器已有页签草稿，不能泛化为所有编辑器都具备。
4. 设置页的旧 JSON 备份不等于 vault、附件、题集/作答和后台状态的完整快照。
5. 练习导航和页面存在，但 API 检查隔离配置；普通运行环境可能出现入口可见而服务不可用，发布前须统一启用策略。

以上是本轮识别并写入文档的缺口，未修改业务实现。
