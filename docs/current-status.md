## 一期已知局限与复盘

- 笔记 AI 分类可能自动新增知识点，不是所有路径都只推荐已有节点。
- “已掌握”等状态来自应用规则/用户记录，不能代表经验证能力；分析页把时长最少称“薄弱科目”、记录高峰称“最高效率时段”，含义需谨慎。

- 设置页 JSON 是结构化记录导出，不包含上传文件本体，也不等于服务器完整灾备包。
