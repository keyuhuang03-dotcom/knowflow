# 标准解答与用户复盘

本地实现，尚未部署。错题上传后仍立即保存，由原有持久队列后台处理，不改数据库结构。

## 新流程

1. 识别多页题干及条件，忽略学生手写作答、答案和旁注。单独的过程照片保留，但不再送入标准解答请求。
2. 题干清晰时，独立生成分步标准解答、最终答案、简短方法和可选自查项；不推断个人卡点、错因或掌握程度。
3. 题干不清或条件矛盾时停止展示解法。生成不完整时保留照片和题干，支持重试。
4. 用户填写卡点，选择一个或多个错因，或自行填写；均可留空，保存不触发 AI。

## 存储和兼容

`aiAnalysis` JSON 增加 `standardSolution`、`finalAnswer`、`errorOptions`。用户拥有的 `selfReport` 包含 `stickingPoint`、`causes`、`customCause`。

独立 PATCH `{selfReport}` 在事务中合并最新 JSON，不改输入版本，不取消任务。Worker 和人工题干校对均保留最新 selfReport。上传时填写的卡点初始化到 selfReport。AI 返回的个人诊断及 selfReport 被丢弃。

原有 Skill 诊断档案不修改；已有档案的查看、修订与 Word 下载保留在历史详情。新卡片不再提示生成完整手写诊断。历史卡片不会伪装为完整标准解答，需要重新整理生成新解答。

## 验证边界

隔离数据库、模拟 AI 验证流程和保存竞争；模型能否正确解答具体题目需真实题目回归验证。公式继续使用现有 MathText 渲染。没有迁移或改写历史学习数据，没有发布服务器。

本轮验证：36 项测试通过，类型检查与生产构建通过。隔离浏览器验证 390px/1440px 无横向溢出、公式渲染、错因默认不选、保存后刷新回显且不产生 AI 任务。Lint 无错误，保留原有 3 项警告。未测试真实 AI 服务的解题质量与 Safari 实机，未部署。
