# 一期开发与验证说明

本文仅对应一期发布基线 `f8f761e`。当前本地目录含暂停的二期代码，不应直接在该工作区启动后把页面当作一期；本轮不切换、不重置、不修改这些代码。

## 读取与准备

先读 [一期 PRD](prd/PRD.md)、[版本依据](current-status.md) 和 app/AGENTS.md。只读查一期可使用 `git show f8f761e:文件路径`；实际运行需使用独立的一期检出目录及测试数据，不覆盖当前工作区或正式库。此文提供操作说明，本轮未创建运行环境或执行迁移。

一期 npm 配置位于 app，生产 Docker 构建上下文是仓库根。Node.js 22、npm、持久 SQLite/上传目录是运行基础；历史 Skill 文档工具还需 Python 3 及其 requirements。一期没有 pilot:dev、pilot:worker 或资料练习 Worker 启动要求。

## 首次新建一期开发环境

仅在新建且明确使用一期代码的隔离目录执行：

```sh
cd app
test -f .env || cp .env.example .env
npm ci
test -e prisma/dev.db || touch prisma/dev.db
npx prisma migrate deploy
npm run db:bootstrap
npm run auth:configure
npm run dev
```

另开终端在同一 app 目录运行 `npm run worker`。通常访问 http://localhost:3000 ，来源配置须与实际域名/地址一致；不要覆盖已有 .env 或个人数据库。旧演示 seed 不用于升级已有数据。

图片识别配置为 MISTAKE_AI_API_KEY、MISTAKE_AI_BASE_URL、MISTAKE_AI_MODEL；文本分类/复盘使用相应文本模型配置，不能互相替代。模型配置失败保留来源，不输出密钥、密码或私钥。

## 适用检查

按修改范围选择 `npm run lint`、`npm run typecheck`、`npm test`、`npm run build -- --webpack`。阅读具体测试脚本后确认隔离数据路径。真模型质量、浏览器写入、生产恢复分别验收，不能用构建替代。

不可回退检查：

- 多页照片顺序、裁剪/旋转、草稿及上传重试，失败后原输入保留。
- 错题离页后后台继续，重启/超时可恢复，旧任务不覆盖新输入和 selfReport。
- 保存补充、保存错因与完成复习均保留个人内容；标题/选项/摘要/答案公式正确渲染。
- 目录逐页识别、候选预览、确认导入、分区和历史关联保留。
- 手机一期导航仅当前项高亮；筛选、题数、底部遮挡及桌面布局对照。
- 登录保护、来源/请求限制、完整备份与隔离恢复。生产默认只读检查，不写测试学习记录。

历史 2026-10 验收结果见现状页，不把它们写成本轮重跑。私人截图和证据保留在 data，不提交个人材料。

## 日常定位

| 表现 | 优先核对 |
| --- | --- |
| 本机地址拒绝连接 | 目标一期 Web 是否运行、端口及日志，不先重建数据库 |

| 备份校验失败 | 传输是否完成、校验清单与归档完整性；不要对半包校验 |
