# 教材目录拍照识别

2026-10-09 检查发现：知识库的“添加教材”只连接主教材名称表单；图谱的“AI 添加”只支持文本知识点提取。没有找到可运行的目录照片识别链路。因此本轮补回独立目录照片入口，而非宣称只是隐藏。

## 入口与操作

我的知识库 → 添加教材 → 选择科目 → 拍照识别教材目录。

1. 相册多选或连续拍照，使用共用多页录入组件；逐页旋转、四边裁剪、压缩，支持调整顺序与整批失败重试。
2. 上传目录页，每批1～6张、总大小不超过24MB；需要更多页时分批处理。
3. 点击识别目录。图片调用现有 `MISTAKE_AI_*` 视觉接口，不使用旧文本提取接口的8条限制。支持最多200个目录项、6层路径，结果过长时提示减少页数，不静默保存截断结果。
4. 核对章节路径与页码，可修改或取消某项。页码不清时允许为空，模型不确定提示单独展示。
5. 点击“核对完成，确认添加目录”。仅新增缺少的路径，不移动、重命名或删除已有节点；相同名称在不同章节下可以分别存在。重复完整路径复用原节点，不覆盖已有页码、状态和学习关联。

已有主教材名称不一致时拒绝导入，先通过“管理教材”核对名称，防止把另一本教材目录混入现有骨架。

## 草稿与失败

- 待上传图片复用 IndexedDB 草稿。
- 上传图片URL、识别预览、修改和教材名称保存在浏览器localStorage；刷新后点击“恢复上次目录预览”。存储失败明确提示，当前内存数据仍可继续使用，不承诺刷新恢复。
- 恢复不合法草稿时提示重新上传，不影响数据库。
- 网络或识别失败保留本批照片，可重试；保存失败保留预览。确认保存成功后清除预览草稿，上传原文件不自动删除。
- 识别和保存期间禁用目录图片操作，避免提交期间改换输入。

## 修改文件

- `CatalogPhotoImport.tsx`：科目页照片录入、预览、修改、确认和草稿恢复。
- `knowledge/[subjectId]/page.tsx`：直接展示目录拍照入口。
- `KnowledgeHome.tsx`：添加教材对话框说明入口。
- `/api/subjects/[id]/catalog`：POST只识别，PUT需显式确认才保存。
- `textbook-catalog.ts`：目录验证与事务内逐层追加，复用现有Prisma节点关系。
- `mistake-integration-run.ts`：本地模拟图片接口，验证目录预览不写库、确认门槛、分层保存、重复路径复用及历史关联保留。

没有数据库迁移、新AI服务或新增依赖，没有重建或清空现有教材目录。没有推送GitHub或部署服务器。

## 验证边界

类型检查、生产构建、lint（无错误，3项已有警告）、隔离数据库集成测试通过。无界面Chrome在390px手机尺寸验证入口、相机/相册控件、未上传前禁用识别、无页面错误和横向溢出；未上传个人数据或写入真实数据库。真实教材目录识别准确性与iPhone Safari相机操作仍需用实际目录照片验收，模拟接口不能证明OCR质量。
