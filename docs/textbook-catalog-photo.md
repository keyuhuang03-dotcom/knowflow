# 教材目录拍照识别与替换

更新：2026-10-20。本轮在本地实现和验证；尚未更新服务器。

## 操作流程

我的知识库 → 科目 → 拍照识别教材目录。

1. 拍照或相册多选，逐页旋转、裁剪、压缩并按阅读顺序排列。每批 1～6 页，总大小不超过 24MB。
2. 选择保存方式：默认“替换整本目录”；补拍缺页选择“追加目录页”。替换必须包含完整目录，不能用单页替换整本。超过单批限制时先建立首批，再以追加方式补齐，保存前核对跨批父章节路径。
3. 识别复用已有 `MISTAKE_AI_*` 图片接口，最多 200 项、6 级。强调章节编号、缩进、字号、多栏阅读顺序和跨页延续；保留章节原文、编号与起始页码。不推算缺失页码或结束页码。
4. 查看缩进预览；展开“校对标题、层级与页码”修改完整路径（以 ` / ` 分隔）和页码。页码不清允许空值；异常页码、平铺结构和缺失父章节等提示需要核对，不能保证自动纠正。
5. 点击“预览保存影响”，查看新增、复用、移入历史的节点数量，再确认。预览不写数据库；预览后目录发生变化会拒绝旧确认，要求重新预览。
6. 教材目录默认只展示顶层章节，点击逐级展开小标题；显示起始页码，搜索子节点时展示其祖先路径。刷新后回到折叠状态。

## 数据保留规则

- 同一本教材、相同完整路径的现有节点复用，保留掌握状态、描述、错题、笔记和资料关联。
- 替换模式：更新目录顺序和页码，未匹配旧节点移到“历史目录”，不删除学习数据。识别页码为空时显示待补，不臆造页码。
- 改用另一本教材：建立新骨架，旧节点进入历史，不把旧教材学习状态直接套到新教材。
- 改名或移动导致路径不一致时视为新节点；旧内容保留在历史节点，不自动猜测、迁移关联。
- 追加模式：保留现有目录，补充缺少节点，更新明确识别的页码。教材名称与现有主教材不一致时拒绝追加。
- 历史节点不进入当前目录、普通图谱和新错题 AI 候选。旧错题和笔记仍能打开历史节点。
- 后台 AI 完成写入前再次核对节点是否仍有效，防止目录替换期间关联到已归档节点。

## 草稿与失败

图片草稿复用 IndexedDB。上传地址、识别预览、保存模式和教材名称保存到 localStorage；刷新后可恢复预览，但必须重新检查保存范围。旧版没有保存模式的草稿按追加模式恢复。

存储失败明确提示，当前内存预览可继续使用，但不能保证刷新恢复。识别或保存失败保留输入，保存成功才清除草稿；上传原图不自动删除。识别、上传和保存期间禁用冲突操作。

## 实现与迁移

- `app/src/lib/textbook-catalog.ts`：验证、事务预览/保存、版本冲突校验、归档与复用。
- `app/src/lib/catalog-recognition.ts`：共用目录识别提示。
- `app/src/app/api/subjects/[id]/catalog/route.ts`：POST 识别；PUT 预览与显式确认。
- `app/src/components/knowledge/CatalogPhotoImport.tsx`：多页录入、层级预览、替换/追加、草稿。
- `app/src/components/knowledge/SubjectCatalog.tsx` 和 CSS module：折叠目录、搜索、历史入口。
- `knowledge-data.ts`、知识 API 与 AI 候选入口：默认排除历史节点；历史详情兼容。
- 迁移 `20261020090000_catalog_revision`：KnowledgeNode 新增 `catalogArchived`（默认 false）、`catalogOrder`（默认 0）。仅加字段，无删表、重建或数据清空。

未新增依赖或 AI 服务。服务端发布必须先备份，再运行现有迁移流程；本轮不在小内存服务器现场构建，待本地验收后统一发布预构建镜像。

## 2026-10-20 实际六页目录修正

用户实拍图暴露了上一轮验收的遗漏：本地数学仍保留 16 个旧骨架节点（包括集合论、关系代数），不是已导入的教材目录。新增 `catalogImported` 来源标记（迁移 `20261020100000_catalog_provenance`，默认 false），只有通过目录保存的节点才进入“教材目录”；未确认旧知识点仍能从个人知识目录访问，替换后转入历史。

长目录识别改为 `[层级,标题,页码]` 紧凑序列，服务端验证层级连续性后生成完整路径，避免重复输出父路径耗尽输出长度。保留旧 entries 格式兼容，拒绝明确标记截断的结果。输出上限调整为 12000 tokens、请求超时 90 秒。补充弯曲点线追踪、分组标题及忽略相邻页残片规则。

真实六页照片两次调用均返回 12 章、180 项，单次约 13 秒。首轮逐图复核校正了 27 处页码；加强规则后仍有 13 处与校对版本不一致（包括误给无印刷页码的章节赋值）。因此不能宣称 OCR 页码已完全可靠，必须保留预览与校对。此次本地保存的是对照照片校正后的版本，章节没有印刷页码时保持为空；没有硬编码该教材到识别器。

私有识别原始结果、复核结果和校对版本位于 `data/deployment/20261020-catalog/`，不提交 Git。保存前完整备份位于 `data/backups/before-real-catalog-20261020/snapshot.tar.gz`。本地建立180个新目录节点，原16个数学节点归档；逐表验证其余业务表和关联表完全不变，旧节点仅归档标志变化，SQLite完整性和外键检查通过。

此改动与校对数据仅在本地，未更新服务器。未来部署应单独迁移校对目录并保留服务器新产生的学习数据，不能用本地整库覆盖线上数据库。
