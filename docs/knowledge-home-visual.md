# 我的知识库：参考图视觉还原

仅对 `/knowledge` 使用新的视觉层。复用 GlassCard B（透明度 72%、模糊 12px、高光 90%、阴影 18%，无折射），采用奶白 `#FAFAF7` 与青柠 `#C5E86C`，四个学科叠加轻微绿、黄、杏、紫柔光。

## 修改范围

- `app/src/app/knowledge/page.tsx`：保留 getCatalog 数据读取与动态页面，交给知识库专属视图；添加本页标题。
- `app/src/components/Sidebar.tsx`：仅 pathname 为 `/knowledge` 时显示专属导航；其他页面保留原导航和交互。
- `app/src/components/knowledge/home/KnowledgeHome.tsx`：搜索栏、真实学科卡片、教材选择、快捷错题入口。
- `KnowledgeSidebar.tsx`：参考图导航、品牌与吉祥物，移动端折叠菜单。
- `KnowledgeHome.module.css`：所有视觉样式作用域化；body/main 的布局调整仅在知识库视图存在时生效。
- `app/public/knowflow/*.svg`：根据用户参考图重新绘制的四张学科插画与三个吉祥物姿态，无 Emoji，无外部素材下载或依赖。
- `app/tests/knowledge-home.browser.mjs`：可选无界面浏览器只读回归；沿用 design-lab 文档中的 KNOWFLOW_PLAYWRIGHT、KNOWFLOW_CHROME 参数。

未修改数据库、API、业务服务、路由地址、其他页面样式或 GlassCard 实验规范；未推送、部署。

## 数据和交互

- 学科卡片来自真实 Catalog，按数学、英语、408、政治优先排列；其他已有科目继续显示，不删除、不补建数据库记录。
- 教材状态来自 textbookTitle。当前没有教材名称时显示“尚未添加教材”，不复制参考图中的书名。
- 已掌握数量 = status 为 mastered 的节点数；分母为当前科目全部节点数量，与现有图谱状态定义一致。0 节点进度为 0，不除以零。
- 卡片和箭头进入原科目页；更多菜单进入已有教材与目录管理。
- 添加教材弹出科目选择，之后仍在原有 TextbookForm 中填写与确认，不另建数据接口。
- 搜索实际已有科目、教材和知识路径，节点结果可直接打开；支持 Command/Ctrl+K 聚焦、Escape 清除。没有接入跨页面错题/笔记全文搜索，因此提示文字没有假称支持它们。
- 添加错题继续进入原有向导；账户入口继续进入设置。

## 与参考图的差异

原图没有提供独立素材，项目也没有原版手绘插画。本轮是 SVG 造型重绘，布局、主题与位置贴近参考图，但纸张笔触、吉祥物细节不保证像素级一致。有原始透明 PNG/SVG 后可以直接替换同名素材。

实际教材和掌握数量与原图示例不同，按真实数据展示。通知仅保留静态铃铛和“暂未接入”提示，不伪造未读通知或添加通知业务。窄屏改为单列，吉祥物缩小、导航折叠，确保内容可读。

- lint 无错误，保留 notes 两条图片警告和 GraphView 一条 effect 警告。

尚未验证真实 Safari/iPhone、长时间滚动性能和操作系统减少透明度设置下的真机表现。使用 B 方案的标准/prefixed backdrop-filter 及实底降级，不能将 Chrome 移动仿真称为 Safari 测试通过。

## 桌面比例调整

根据实际使用反馈收紧桌面布局：侧栏 224px、顶栏 46px，标题与学科卡片字号适当减小，减少卡片内部和区域间留白。高度不超过 800px 时使用更紧凑的标题、卡片与上下边距；未使用 zoom/transform 整页缩放或隐藏溢出来强行塞进屏幕。手机单列保持不变。真实长教材名或新增学科仍允许页面自然滚动。
