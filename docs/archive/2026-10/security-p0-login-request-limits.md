# 上线加固：单人登录与请求体限制

## 本轮行为

- `/login` 使用现有KnowFlow奶白背景、青柠绿、品牌SVG和玻璃设计Token，独立展示，不显示业务侧栏。设置页可退出登录。
- 单人账号由私有环境变量配置，不新增用户表或迁移。scrypt盐化密码哈希；签名会话7天到期，使用HttpOnly、SameSite=Strict Cookie，HTTPS来源加Secure。密码哈希或签名密钥变化后旧会话失效。
- 登录配置缺失或公开生产来源不是HTTPS时拒绝访问。没有开发后门、默认密码或自动启用的无鉴权模式。
- Proxy保护页面与私有资源，根布局再次验证会话；每个业务API和动态上传文件路由独立使用withAccess，不只依赖Caddy或Proxy。仅登录页、登录API及必要的品牌/静态脚本资源公开。
- 未登录API、照片、导出返回401；业务页面跳转登录。写操作严格匹配APP_ORIGIN并拒绝cross-site，阻止跨站写入。响应不缓存私人API数据。
- 登录并发最多2个，失败尝试单Web进程5分钟内最多5次，返回429。当前为单人实例的进程内保护，进程重启会重置；不支持多实例共享限流。
- 退出清除当前浏览器会话并完整跳转以清除客户端状态。签名会话不是服务端会话库：复制的旧Cookie不会因另一浏览器退出立即作废，需到期或更换密码/密钥统一撤销。

## 请求大小

| 请求 | 代理与应用上限 |
| --- | --- |
| `/api/upload` | 26MiB整个请求；原业务仍限制6页、每页10MiB、图片总计24MiB |
| `/api/auth/login` | 4KiB |
| 其他API请求体 | 1MiB |

Caddy模板在读取/转发前限制请求体。应用先校验会话、来源和Content-Length，再按流累计字节、超限取消读取，最终才交给原处理器解析formData/json；没有Content-Length也执行限制。Next Proxy克隆请求缓冲另设26MiB上限，此实验性选项不是硬拒绝规则，不能替代Caddy和应用计数。

导入大型JSON备份受1MiB上限约束；不要盲目调大所有接口限额。大备份应停写后走离线恢复流程并先备份，不覆盖唯一数据副本。浏览器不能把响应中的确认标记当作认证凭据。

## 配置和本地验收

在交互终端执行，不要把密码写在命令参数或聊天里：

```sh
cd /Users/huangkeyu/kaoyan-workbench/app
npm run auth:configure
npm run dev -- --hostname 0.0.0.0
# 如需后台整理，另开终端，在app中运行
npm run worker
```

脚本输入账号、完整网页来源和两次密码（12～256位、不回显），保留已有AI配置，将哈希和随机签名密钥原子写入600权限的`.env`。不输出密码或密钥。重新配置会更新密钥，重启Web后全部旧会话失效。

来源必须与浏览器一致：电脑可用`http://localhost:3000`；手机开发验收填写实际电脑局域网地址，例如`http://192.168.1.10:3000`。公开生产配置必须用`https://study.koayan.cn`；不会自动接受任意Host或来源。一个配置只允许一个来源，使用另一地址写入会被拒绝。

1. 未登录打开知识库应进入登录页；直接请求`/api/backup`、照片和Word导出应401。
2. 错密码提示、输入保留；正确登录后进入原页面；设置页退出后私有资源重新不可访问。
3. 多页拍照保存、刷新恢复、网络失败重试和后台处理正常。
4. 密码或密钥更新并重启后，旧浏览器会话不能访问API。

此轮未为用户生成默认口令，未修改真实`.env`。上线前必须执行配置命令。

## 服务器边界

`compose.yaml`没有将Web的3000映射到宿主机，只由Caddy发布80/443。即使直接访问应用端口，应用登录仍有验证；网络层仍应验证公网3000不可达，防止绕过代理请求体限制。

更新时保留真实`deploy/app.env`、`deploy/Caddyfile`及data；先备份，核对模板差异，手动加入登录配置和请求限制，不覆盖既有域名/证书/其他配置。可在本地app运行`npm run auth:configure -- ../deploy/app.env`，仅在私有配置中设置生产来源，再安全传输并设600权限。

新模板默认用网页登录。已有Caddy Basic Auth可保留作外层保护，会额外显示浏览器密码弹窗；确认应用验证正常后才取消。不要先移除已有保护，再部署未配置好的应用。

服务器验收：HTTPS实际有效；未登录API/照片/导出被拒；代理超限返回413；公网3000不可达；Worker和Web共用持久目录且离页仍处理。备案仍是用户报告待通过状态，本轮未核验备案、DNS或服务器。
