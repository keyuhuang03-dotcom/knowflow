# KnowFlow 上线前检查与本地验收

日期：2026-10-13。仅本地修改，无 GitHub 推送或服务器部署。保留现有未提交修改、数据库、照片和学习资料。

## 本轮落实

- 页面、API、照片和导出均有应用登录保护；生产配置缺失时拒绝启动/访问。会话绑定来源和密码配置。登录按可信客户端IP、全局次数及并发分别限制。
- Caddy 模板提前限制上传26MiB、普通JSON1MiB、登录4KiB，并限制慢请求。应用在解析前独立累计检查请求体，限制并发和读取时间；API不经过Proxy的额外请求体复制。线上3000不发布。
- SQLite每日AI整理额度原子扣减，Web和Worker共享，进程重启不会清零；保留失败照片，可日后重试。新增 `AiUsageDay` 表，不改历史业务表。
- 图片解码限制20MP与单帧，损坏/过大图片提供提示。用户、日期、学习时长、知识状态、关联等输入增加边界检查。
- 整库导入先校验版本、字段、引用和日期，再生成完整安全快照；恢复期间拒绝其他写入，Worker运行时拒绝导入。生产默认关闭网页整库恢复。JSON导出有内存上限，完整备份不截断照片。
- 完整备份包含SQLite、上传和Skill文件、逐文件与压缩包SHA-256；工具验证路径安全、校验值、SQLite完整性和外键。服务器维护有互斥、停写、暂存迁移、旧目录保留。手动下载到Mac，不配置自动异地传输。
- Docker运行用户为非root，限制内存/CPU、日志大小、权限和可写目录；Web/Worker健康检查、启动迁移和安全初始化均已准备。tsx移至运行依赖，版本未变。

## 本地验收

在仓库根目录运行 `npm --prefix app run dev`，另一个终端运行 `npm --prefix app run worker`。访问 http://localhost:3000/login；本地APP_ORIGIN必须对应这个地址，不能使用尚未部署的域名。来源/密码配置变更后重新登录。

1. 未登录访问错题API、原图、导出应被拒绝，登录后原功能可用。
2. 上传多页照片后立刻保存，可离开页面；刷新/回看整理状态。相机、裁剪及图片方向在手机真机验收。
3. 临时隔离测试配置中关闭AI，照片和记录仍存在，提示可重试；不要清空个人生产配置。每日额度到达后不再调用模型，不影响查看和手工编辑。
4. 验收原有笔记、教材骨架、历史卡片、多知识点关联与编辑；日期/时长非法输入有提示。
5. 完整备份校验并解压到新空目录，核对照片与数据库。不要直接把测试备份导入个人数据库。
