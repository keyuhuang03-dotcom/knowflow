# 错因与补充统一保存

复现：在错因栏输入文字后点“保存补充”，旧版只写入 userNote；刷新后 customCause 为空。独立错因组件还会在练习/编辑切换时卸载，重新从旧页面属性初始化。

修复：错因草稿提升到详情页，保存错因、保存补充、完成复习和编辑保存均提交当前 selfReport；API 在同一事务中合并最新分析与用户错因，同时写入补充和复习状态。仅保存错因/补充不修改 inputVersion、不启动 AI。输入无效时整笔请求失败，不部分写入。切换错题时按记录 ID 重置详情状态，练习切换保留当前草稿。

验证：旧版浏览器测试复现失败；新版浏览器测试覆盖三个保存入口、刷新、练习切换、网络失败保留草稿及重试，手机/桌面布局无溢出。40 项测试通过，含后台 AI 保留用户错因、组合保存和无效请求不部分写入；类型检查、生产构建通过；lint 无错误，3 个既有警告。

未验证 iPhone Safari 真机；线上验证不会修改用户学习记录。
