# 知序 KnowFlow

个人学习工作台：保存错题和课堂笔记，通过知识点链接找回学习材料，并把现有资料整理为在线练习。

## 网站能做什么

- **知识库**：按学科浏览；数学一高数极限以完整网状图谱展示知识关系，连接笔记与错题。
- **错题**：照片先保存，后台 AI 整理题干和解答，用户补充卡点并确认关联。
- **笔记**：手工创建，或上传课堂照片/PDF 后校对保存，一篇笔记可关联多个知识点。
- **练习**：从图片/PDF 提取原题，校对后作答，有答案的单选题判定，其他情况自评。
- **学习记录与保护**：保存学习进度和复习记录，保留历史内容，支持数据备份与恢复。

当前内置内容是数学一极限局部参考包，不是完整全科知识库。学习进度不等于掌握率；全局薄弱点分析、App 与多端同步尚未实现。

## 运行

已有完整功能开发环境，在 `app/` 两个终端分别执行 `npm run pilot:dev` 和 `npm run pilot:worker`，默认地址 http://127.0.0.1:4321 。这些是现有脚本名称，不代表另一套产品导航。

首次初始化、旧环境启动、PDF 依赖及数据隔离请按 [开发说明](docs/development.md) 操作。普通 `npm run dev` 不会自动启用所有新内容服务。已有学习数据和配置不得覆盖。

本页描述当前实现，不承诺所有能力已在正式站部署。业务代码在 `app/`，维护文档在 `docs/`；个人文件、数据库、备份及本机验收证据在被 Git 忽略的 `data/`。开发发布遵循 [协作规范](CONTRIBUTING.md)，不提交密钥和个人数据。
