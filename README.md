# 知序 KnowFlow

已完成并上线的一期个人考研学习工作台：以教材知识目录为骨架，连接错题、笔记与学习记录，支持多页拍照保存、后台 AI 整理和用户复盘。

本仓库文档用于整理一期项目成果与实习作品集。**本地二期开发分支暂缓，不属于一期交付；文档不再将其实验功能写成已上线能力。**

## 一期已交付

- 教材目录：按学科/部分上传多页目录，后台识别、校对后确认导入。
- 错题：照片和记录先保存，后台识别题干与生成解答，用户填写卡点、确认关联。
- 知识库与原有图谱：浏览节点及关联的错题、笔记；图谱使用 vis-network。
- 笔记：手工正文、附件、标签与 AI 分类，正文保存在 SQLite。
- 学习支持：学习时长、任务、复习记录、每日总结，以及登录、备份和恢复保护。

手机一期导航为首页／知识库／拍照／记录，首页仍有录入教材目录入口。Reagraph 极限图谱、MD 正文、照片笔记转录及资料刷题属于二期期望，不计入上述成果。
